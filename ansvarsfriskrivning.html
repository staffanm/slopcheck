Ansvarsfriskrivning

Slopcheck är ett experimentellt verktyg. Vi gör vårt bästa för att skydda din text och för att bedömningarna ska vara korrekta, men vi lämnar inga garantier eller utfästelser.

Ingen juridisk rådgivning

Slopcheck ger ingen juridisk rådgivning. Resultaten är maskinella och ska granskas av dig. Ett resultat är inte ett besked om gällande rätt eller om ett dokuments riktighet.

Ingen garanti för riktighet

Verktyget kan missa hänvisningar, tolka påståenden fel, missa villkor och undantag och blanda ihop vem som uttalat sig. En hittad källa betyder inte att den stöder påståendet. Att stöd saknas betyder inte att påståendet är fel. Textutvinning ur PDF och Word kan bli fel. Historiska lydelser och täckning i källorna kan skilja sig. Du ansvarar själv för att kontrollera slutsatser mot primärkällorna.

Sekretess så långt vi kan

Vi strävar efter att behandla din text med sekretess. I normalläge skickas text till lagen.nu för att hitta hänvisningar, och påståenden med utvalda källavsnitt skickas till Slopchecks server för jämförelsen. Dessa data behandlas tillfälligt, sparas inte och skickas inte vidare. I integritetsläge stannar dokumentet och dina hänvisningar på din enhet. Vi kan ändå inte garantera sekretess mot fel, avbrott eller omständigheter utanför vår kontroll. Läs Så funkar det för vad som lämnar din webbläsare i varje läge.

Inga åtaganden

Tjänsten tillhandahålls i befintligt skick, utan garantier av något slag. Vi åtar oss inte tillgänglighet, felfrihet eller lämplighet för ett visst ändamål. Vi ansvarar inte för beslut som fattas på grund av resultaten eller för skada som följer av att tjänsten används.
